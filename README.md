2. C++ was developed by Bjarne Stroustrup, as ab extension to the C laguage.
3. C++ gives programmer a high level of control over system resources and memory

# Why use C++ ?

1. C++ is one of the most world's popular programming languages.
2. C++ can be found in today's operating system, Graphical User Interfaces, and embedded system.
3. C++  is an object-oriented programming language which gives a clear structure o programs and allows code to reused, lowering development costs.
4. C++ is portable and can be used to develop applications that can be adapted to multiple platform.
5. C++ is fun and easy to learn.
