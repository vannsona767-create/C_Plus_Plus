# Constractor
    is a special method that automatically when the object of class is created.
        to create the constractor, use the same name as the class, followed by parentheses()
# Rules
1. The constractor has the same name as the class.
2. It has no return type(not even void).
3. It is usually declared public.
4. It is automatically called when the object of class is created

# Constractor overlaoding
    Why Use Constructor Overloading?
1. To give flexibility when creating objects
2. To set default or custom values
3. To reduce repetitive code
